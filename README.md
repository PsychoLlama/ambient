# Ambient

A content-addressed programming language with structural types and abilities, built for programs that exchange code between machines and change while they run.

> [!WARNING]
> Ambient is being rebuilt from scratch and has no users. Expect everything to change.

```sh
cargo run -- run examples/hello -- you
cargo run -- run examples/search -- fn crates/ambient/src/syntax
cargo run -- check examples/tally
```

- [docs/guide.md](docs/guide.md): how to write and run a program.
- [examples/](examples): complete packages.
- [spec/](spec/README.md): what the language is and why. The implementation follows it.
